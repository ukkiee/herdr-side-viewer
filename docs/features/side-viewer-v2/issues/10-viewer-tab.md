# 10: 뷰어 탭

**What to build:** 사이드 뷰어 머리줄의 "새 탭으로 열기"를 누르면 같은 공간의 지금 탭 바로 뒤에 사이드 뷰어 하나만 있는 탭이 생기고 그 탭으로 넘어간다. 탭 이름은 파일 이름이고 보이는 파일을 따라 바뀐다. 뒤로 가기 기록은 비어 있는 채로 시작한다. 고친 내용이 있으면 새 탭으로 옮겨 가고 원래 뷰어는 디스크 내용을 보여 준다. 뷰어 탭이 보이는 동안의 열기 요청은 그 탭이 받는다.

**Blocked by:** 02

**Status:** ready-for-agent

**명세:** `docs/features/side-viewer-v2/spec.md` (AC-8, AC-9, AC-10, AC-11)

**파일 소유:** 새 뷰어 탭 넘김 모듈(넘김 파일 형식, 탭 위치)과 그 테스트. 연결 파일 자리: 머리줄 모듈의 새 탭으로 열기 자리, `main.js`의 넘김 받기·탭 이름·기록 새로 시작 자리, 편집 상태 모듈의 고친 내용 넘기기·받기 함수.

**설계 계약:**
- 넘김 모듈: 명세 "구현 결정"의 "뷰어 탭", v1 `mods/side-viewer/request.js`의 요청·응답 파일 방식
- 탭 명령: `herdr-app commands`의 `tab.new`·`tab.move`·`tab.rename`, `herdr-app --skill`
- 용어: `GLOSSARY.md`의 "뷰어 탭"

**검증 방법:**
- 경계 1: 넘김 파일 형식(쓰기·읽기·오래된 넘김 버리기), 지금 탭 다음 위치 계산, 고친 내용 넘기기 뒤 원래 뷰어 상태
- 경계 2: 보이는 뷰어가 응답하면 분할하지 않는 기존 테스트 통과
- 경계 4: 새 탭 위치·이름·포커스, 같은 파일로 두 번 열기, 링크로 이동할 때 탭 이름, 고친 내용 옮기기, 뷰어 탭에 cmd-클릭 요청

- [ ] 새 탭이 지금 탭 바로 뒤에 파일 이름으로 생기고 그 탭으로 넘어간다
- [ ] 같은 파일이어도 새 탭을 만든다
- [ ] 탭 이름이 보이는 파일을 따라가고, 기록은 비어 있게 시작한다
- [ ] 고친 내용이 새 탭으로 옮겨 가고 원래 뷰어는 디스크 내용이다
- [ ] 보이는 뷰어 탭이 열기 요청을 받고 pane이 늘지 않는다

**완료 조건:** 위 항목 전부, 경계 1·2 통과.
