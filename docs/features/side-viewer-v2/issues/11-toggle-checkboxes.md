# 11: 체크박스 눌러 바꾸기

**What to build:** 렌더링의 체크박스를 누르면 체크가 바뀌고 원문의 그 줄이 `[ ]`↔`[x]`로 바뀐다. 그 파일에 고친 내용이 없으면 바로 저장하고, 저장 순간 디스크가 바뀌어 있으면 쓰지 않고 "밖에서 바뀌었습니다" 막대를 띄운다. 고친 내용이 있으면 그 수정에 더해져 "저장 안 됨"으로 남는다.

**Blocked by:** 03, 04

**Status:** integrated

**명세:** `docs/features/side-viewer-v2/spec.md` (AC-21)

**파일 소유:** 새 체크박스 바꾸기 함수(순수)와 그 테스트. 연결 파일 자리: 블록 해석 모듈의 체크박스 항목 줄 번호 필드, 마크다운 보기 모듈의 체크박스 자리, 편집 상태 모듈의 바꾼 글 합치기 함수, `main.js`의 체크박스 누름 연결.

**설계 계약:**
- 바꾸기 함수: 명세 "구현 결정"의 "체크박스 바꾸기(순수)", AC-21
- 저장과 충돌: 02·03의 편집 상태 모듈, 명세 AC-4

**검증 방법:**
- 경계 1: 줄 번호로 `[ ]`·`[x]`·`[X]` 바꾸기, 같은 글의 다른 줄이 바뀌지 않음, 고친 내용 있음/없음에 따른 결과, 디스크가 바뀐 경우
- 경계 4: 할 일 목록을 눌러 파일이 바뀌는지, 원문을 고친 상태에서 누르기, 밖에서 바뀐 상태에서 누르기

- [x] 누르면 체크와 원문 줄이 바뀐다 (경계 1·3과 코드 대조. 실제 앱 확인은 미실행, 12에서 한다)
- [x] 고친 내용이 없으면 바로 저장된다 (경계 1·3과 코드 대조. 실제 앱 확인은 미실행, 12에서 한다)
- [x] 고친 내용이 있으면 "저장 안 됨"으로 남는다 (경계 1·3과 코드 대조. 실제 앱 확인은 미실행, 12에서 한다)
- [x] 디스크가 바뀌었으면 쓰지 않고 막대가 뜬다 (경계 1·3과 코드 대조. 실제 앱 확인은 미실행, 12에서 한다)

**완료 조건:** 위 항목 전부, 경계 1 통과.
