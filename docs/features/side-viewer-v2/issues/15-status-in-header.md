# 15: 저장 실패·충돌을 머리줄의 상태 글로 보이기

**What to build:** 머리줄 아래의 막대를 없애고, 고친 내용이 있을 때의 상태를 머리줄의 한 자리(지금 "저장 안 됨" 자리)에 해요체로 보인다. 고친 것만 있으면 "편집됨"과 [저장], 저장 실패면 "쓰기 권한이 없어요"·"파일이 지워졌어요"·"너무 커서 저장할 수 없어요"·"저장하지 못했어요"(마우스를 올리면 오류 내용)와 [저장], 디스크가 밖에서 바뀌었으면 "외부에서 바뀌었어요"와 [다시 읽기]·[덮어쓰기](저장 버튼 대신). 실패·충돌 글은 빨간색이고, 잘리면 마우스를 올려 전문을 본다.

**Blocked by:** 03, 10, 11, 14 (모두 integrated)

**Status:** integrated

**명세:** `docs/features/side-viewer-v2/spec.md` (AC-2, AC-3, AC-4, AC-5, AC-10, AC-21의 "편집됨"과 AC-4의 표시, "구현 결정"의 "화면", "상태와 실패")

**결정 근거:** 2026-11-12 손 확인(RECIPE v2 12번 "저장하기에는 너무 큽니다." 막대) 중 사용자: "저장 안 됨칸에 저장하기에는 너무 큽니다로 보여주는게 어때" → 범위 "전부다(충돌 포함)", 말투 해요체, 노트 "밖에서 보다 외부", "쓸권한보다" → 주 진행자 제안 "쓰기 권한이 없어요"로 합의, "저장안됨 -> 편집됨". 보완(빨간 글자, 충돌은 저장 버튼 대신 두 버튼, 잘리면 마우스 올려 전문)도 합의.

**파일 소유:** `mods/side-viewer/header.js`(상태 글과 버튼 자리), `mods/side-viewer/edit-state.js`와 그 테스트(상태 글 문구: `barOf`·`MESSAGES`를 상태 글로; 상태 판단의 뜻은 바꾸지 않는다), `mods/side-viewer/main.js`(머리줄에 상태와 콜백 넘기기, 막대 자리 지우기), `mods/side-viewer/conflict-bar.js`(지우거나 머리줄 그리기로 옮기기), README.md·README.ko.md·RECIPE.md의 막대·"저장 안 됨"·실패 문구.

**설계 계약:**
- 상태 판단: 티켓 02·03의 `edit-state.js`(`unsaved`, `barOf`, `diskRead`, `saveFailed`, `discarded`, `overwritten`), 리뷰 CR-2·L-1(`refusalOf`, `messageOf`)
- 머리줄: 티켓 01·02·08·10의 `header.js`(순서: 뒤로 가기, 이름·폴더, 상태 글·버튼, 두 칸 전환, 새 탭, 원래 앱, Finder; 좁으면 이름·폴더 말줄임, 버튼은 남음)
