# 03: 밖에서 바뀐 파일과 저장 실패

**What to build:** 고친 내용이 있을 때 파일이 디스크에서 바뀌면 뷰어가 다시 읽지 않고 "밖에서 바뀌었습니다" 막대를 띄운다. [내 수정 버리고 다시 읽기]는 디스크 내용을 보여 주고, [내 것으로 덮어쓰기]는 내 내용을 저장한다. 저장할 때 디스크가 바뀌어 있으면 쓰지 않고 같은 막대를 띄운다. 권한 없음, 파일 지워짐, 1 MiB 초과로 저장이 실패하면 같은 자리에 이유를 보여 주고 수정은 남긴다. 고친 내용이 없으면 v1처럼 알아서 다시 읽는다.

**Blocked by:** 02

**Status:** ready-for-agent

**명세:** `docs/features/side-viewer-v2/spec.md` (AC-4, AC-5)

**파일 소유:** 막대 그리기(새 모듈 또는 02의 머리줄 아래 자리, `mods/side-viewer/` 아래). 연결 파일 자리: 편집 상태 모듈의 디스크 변경·저장 결과 해석 함수, `main.js`의 감시 반응 자리.

**설계 계약:**
- 해석 함수: 명세 "구현 결정"의 "편집 상태", "저장", "상태와 실패"의 "충돌"·"저장 실패"와 안내 문구
- 감시: v1 명세 "구현 결정"의 "새로고침"
- 저장 거부: `~/.config/herdr-app/herdr.d.ts`의 `writeTextFile` 설명
- 막대 모듈: 없음(확인한 곳: `AGENTS.md`, `CLAUDE.md`, `docs/adr/`, `docs/agents/`, `GLOSSARY.md`)

**검증 방법:**
- 경계 1: 디스크 변경 × 고친 내용 있음/없음, `writeTextFile` 거부의 해석(밖에서 바뀜, 권한, 지워짐), 1,048,576바이트 경계, 두 버튼 뒤의 상태
- 경계 3: `herdr-app check mods/side-viewer`와 막대가 보이는 상태의 임시 사본 check
- 경계 4: 고치는 중에 셸에서 같은 파일을 바꾸기, 권한을 없앤 파일에 저장, 파일을 지운 뒤 저장, 1 MiB 넘게 붙여 넣고 저장

- [ ] 고친 내용이 있을 때 밖에서 바뀌면 막대가 뜨고 다시 읽지 않는다
- [ ] 두 버튼이 명세대로 동작한다
- [ ] 저장 순간 디스크가 다르면 쓰지 않고 막대가 뜬다
- [ ] 세 가지 저장 실패가 이유와 함께 보이고 수정이 남는다
- [ ] 고친 내용이 없으면 v1처럼 다시 읽는다
- [ ] mod 오류가 나지 않는다

**완료 조건:** 위 항목 전부, 경계 1·3 통과.
