# 04: 코드 보기, 이미지 보기, 그릴 수 없는 파일 안내

**What to build:** 사이드 뷰어가 확장자에 따라 보기를 고른다. 코드·텍스트는 줄 번호와 문법 색상이 있는 읽기 전용 코드 보기, 이미지는 뷰어 폭을 넘지 않는 그림이다. 그릴 수 없는 파일(1 MB 초과 텍스트, 20 MB 초과 이미지, 넘겨받은 확장자가 아닌 파일, 읽을 수 없는 파일)은 이유 안내만 보여 주고 mod 오류를 내지 않는다.

**Blocked by:** 02

**Status:** ready-for-agent

**명세:** `docs/features/side-viewer/spec.md` (AC-3, AC-9)

**파일 소유:** 보기 판별 모듈과 이미지 사본 관리 모듈(새 파일, `mods/side-viewer/` 아래)과 그 테스트. 연결 파일: `mods/side-viewer/main.js`의 본문 그리기 분기 자리. 확장자 목록 파일은 읽기만 한다(소유 01).

**설계 계약:**
- 보기 판별 모듈: 명세 "구현 결정"의 "보기 판별", AC-3·AC-9의 확장자와 크기 숫자
- 이미지 사본 관리 모듈: 명세 "구현 결정"의 "이미지 그리기"(확장자와 머리 바이트 확인, 30일 정리)
- `main.js`의 해당 자리: 명세의 연결 파일 표, `~/.config/herdr-app/AGENTS.md`의 "UI" 절(`EditorState`·`Editor`, `image`)

**검증 방법:**
- 경계 1: 확장자 → 보기·색상 언어, 크기 경계값(정확히 1 MB/20 MB, 그 초과), 이미지 머리 바이트 판별 단위 테스트
- 경계 3: `herdr-app check mods/side-viewer`
- 경계 4: 실제 앱에서 코드 파일, 이미지, 큰 파일을 열어 확인

- [ ] 코드·텍스트 파일이 줄 번호와 문법 색상이 있는 읽기 전용 화면으로 보인다
- [ ] 색상 언어를 모르는 확장자는 색 없이 보이고 오류가 없다
- [ ] 이미지가 뷰어 폭을 넘지 않게 보이고, 뷰어를 좁히면 따라 줄어든다
- [ ] 확장자는 이미지지만 내용이 이미지가 아닌 파일은 사본을 만들지 않고 안내를 보여 준다
- [ ] 1 MB 초과 텍스트, 20 MB 초과 이미지, 넘겨받은 확장자가 아닌 파일, 읽을 수 없는 파일이 각각 이유 안내로 보인다
- [ ] `herdr-app check`가 통과한다

**완료 조건:** 위 항목 전부, 경계 1 테스트와 경계 3 통과.
