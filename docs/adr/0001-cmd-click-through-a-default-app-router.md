# cmd-클릭은 기본 앱 자리를 넘겨받은 라우터로 받는다

Herdr 앱의 mod는 터미널 글자에 대한 클릭을 받을 방법이 없다(mod API에 해당 훅이 없음, 2026-11-11 `herdr-app 0.1.13`의 `AGENTS.md`·`herdr.d.ts` 검색 기준이며 실행으로 부재를 증명한 것은 아니다). 반면 Herdr는 경로를 cmd-클릭하면 macOS에 그 파일을 열어 달라고 넘기고, 이는 에이전트 창의 절대·상대·줄 번호·코드 표기 경로 모두에서 동작함을 직접 눌러 확인했다. 그래서 라우터라는 백그라운드 앱을 넘겨받은 확장자의 기본 앱으로 등록해 그 클릭을 받고, Herdr가 앞에 있을 때만 사이드 뷰어로 보낸다.

## Considered Options

- **단축키로 화면의 경로 목록을 띄워 고르기(picker).** 기본 앱 설정을 건드리지 않고 모든 파일에 통하지만, 사용자가 "누르면 열린다"를 원해 택하지 않았다.
- **shift+클릭.** mod가 클릭을 받을 수 없고 Shift는 터미널의 글자 선택에 쓰여 불가능하다.

## Consequences

- macOS 전용이다.
- 넘겨받은 확장자는 Finder 등 Herdr 밖에서 열어도 라우터를 한 번 거친다. 확장자별 원래 앱을 기억해 그쪽으로 넘기고, 되돌리기로 전부 복구할 수 있어야 한다.
- macOS는 확장자가 아니라 파일 종류 단위로 기본 앱을 정하므로, 넘겨받을 수 없거나 다른 확장자까지 딸려 오는 확장자는 목록에서 뺀다.
